`Strict-Transport-Security` no aparece en esta captura porque se hizo sobre `:4200` (HTTP plano,
proxy del frontend) — Spring Security nunca la envía en texto plano. Confirmada sobre HTTPS en la
misma sesión de medición, ver `a02-tls.txt`:

Strict-Transport-Security: max-age=31536000 ; includeSubDomains

Las demás cabeceras de seguridad (nosniff, X-Frame-Options, CSP, Referrer-Policy,
Permissions-Policy) sí están presentes sobre HTTP plano porque Spring Security las añade
independientemente del esquema de transporte.
