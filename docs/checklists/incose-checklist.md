# Checklist INCOSE

*International Council on Systems Engineering - Criterios de calidad para Requisitos.*

## 1. Características Individuales de los Requisitos
- [ ] **Necesario:** ¿Define una función esencial?
- [ ] **Independiente:** ¿Se puede entender por sí solo sin contexto implícito?
- [ ] **No ambiguo:** ¿Tiene una única interpretación clara?
- [ ] **Verificable:** ¿Existe una forma medible u objetiva de comprobar que se cumple (ej. con pruebas)?
- [ ] **Singular:** ¿Describe una única capacidad o restricción (no usa "y/o" para agrupar diferentes requisitos)?
- [ ] **Libre de diseño:** ¿Define *qué* debe hacerse, en lugar de *cómo* debe implementarse?

## 2. Características del Conjunto de Requisitos
- [ ] **Completo:** ¿Cubre todas las necesidades conocidas de los stakeholders?
- [ ] **Consistente:** ¿No existen contradicciones entre dos o más requisitos?
- [ ] **Factible:** ¿Se puede implementar con las tecnologías y recursos actuales?
- [ ] **Trazable:** ¿Cada requisito está enlazado a su origen (ej. objetivos de negocio) y a sus pruebas/implementación?
