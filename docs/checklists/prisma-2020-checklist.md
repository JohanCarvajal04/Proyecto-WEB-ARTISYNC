# Checklist PRISMA 2020

> [!NOTE]
> **Estado:** No Aplica (N/A)

**Justificación:**
El estándar PRISMA (Preferred Reporting Items for Systematic Reviews and Meta-Analyses) está diseñado específicamente para guiar y evaluar **Revisiones Sistemáticas de la Literatura (SLR)** y Metaanálisis.

Dado que este proyecto (ARTISYNC) es un proyecto de desarrollo de software e ingeniería empírica que no incluye un componente de revisión sistemática de literatura, el uso de PRISMA no es aplicable. Para los aspectos empíricos de evaluación (como las pruebas de usabilidad y rendimiento), se utiliza el estándar de Ralph et al. (2021).
