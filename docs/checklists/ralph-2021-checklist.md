# Checklist de Validación Empírica (Ralph et al. 2021)

*Plantilla basada en los estándares empíricos de ACM SIGSOFT.*

## 1. Diseño del Estudio
- [ ] ¿Se establecieron claramente los objetivos de investigación?
- [ ] ¿Se definió el contexto (participantes, tareas, entorno)?
- [ ] ¿El diseño es adecuado para responder las preguntas de investigación?

## 2. Recolección de Datos
- [ ] ¿Se describen detalladamente los procedimientos de recolección?
- [ ] ¿Se reportan las herramientas utilizadas?
- [ ] ¿Se mitigaron los sesgos en la recolección de datos?

## 3. Análisis de Datos
- [ ] ¿Se documentó el proceso de análisis?
- [ ] ¿Se aplicaron métodos estadísticos o cualitativos apropiados?

## 4. Reporte de Resultados
- [ ] ¿Los resultados responden directamente a los objetivos propuestos?
- [ ] ¿Se incluyeron métricas clave (ej. tamaños de efecto, p-valores, intervalos de confianza)?
- [ ] ¿Se discutieron las limitaciones (amenazas a la validez)?

## 5. Replicabilidad
- [ ] ¿Se provee un paquete de datos (data package) con datos crudos?
- [ ] ¿Los scripts de análisis están disponibles?
